# performance

The neo.performance facade: Web-Performance-style macro profiling — a high-resolution monotonic clock anchored at the script's session origin, plus User Timing marks and measures kept in a bounded per-script buffer. Wall-clock timestamps remain the domain of the ES-native Date.now(); this module measures durations. Each script session owns an isolated timeline, so timeOrigin and buffered entries reset when the script reloads.

Category: Core · Since: 0.2.0 · MC availability: * · Loader availability: * · Exposed as `neo.performance` and `@neomacros/performance`

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `entries` | `Array<`[PerformanceEntry](classes/performanceentry)`>` | All kept entries in insertion order; the buffer keeps the newest 4096 and evicts older ones. (The MDN getEntries() query lands as a read-only property under the house no-argument-property rule.) (read-only) |
| `timeOrigin` | `number` | Wall-clock time, in milliseconds, at which this script's session started; performance.timeOrigin + performance.now() stays comparable to Date.now(). (read-only) |

## Examples

Segment timing around a hot loop — measures accept mark names or raw timestamps:

```js
const { performance } = neo.performance;

performance.mark("batch");
for (let i = 0; i < 100; i++) processOne();
const batch = performance.measure("batch-x100", "batch");
chat.log(`100 items in ${batch.duration.toFixed(2)}ms`);

// Split one span using the timestamps of two marks:
performance.mark("split");
const half = performance.measure("first-half", "batch", "split");
```

Per-tick profiling stays cheap: the buffer is a per-script ring of the
newest 4096 entries, so long sessions never need manual cleanup:

```js
events.on("tick", () => {
  performance.mark("tick-start");
  step();
  performance.measure("step", "tick-start");
});

// Read the latest samples whenever you want:
const recent = performance.entriesByName("step", "measure").slice(-20);
const avg = recent.reduce((sum, entry) => sum + entry.duration, 0) / recent.length;
chat.log(`avg step ${avg.toFixed(3)}ms`);
```

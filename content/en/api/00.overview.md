# API Reference

Everything scripts can touch hangs off the global `neo` object — 16 facades,
each also importable as an ES module (`@neomacros/chat`, `@neomacros/world`,
…). The pages in this section are generated from the annotated mod sources on
every API change, so they always match what the running mod exposes.

TypeScript users get the full surface as
[`neomacros.d.ts`](/neomacros.d.ts) — drop it next to your scripts for
editor autocompletion.

New to NeoMacros? Start with the
[Getting Started guide](../guide/getting-started) or pick a complete script
from the [Examples](../examples/) section.

## Facades

### Core

| Facade | Purpose |
| --- | --- |
| [`events`](./events) | EventEmitter-style subscription: `on` / `once` / `waitFor`, auto-cleanup on unload |
| [`thread`](./thread) | timers, ticks, main-thread dispatch, per-script event loop |
| [`storage`](./storage) | per-script persistent key-value store, JSON-serializable values |

### UI

| Facade | Purpose |
| --- | --- |
| [`chat`](./chat) | send to server, local log lines, action bar messages |
| [`hud`](./hud) | persistent HUD text overlays above the vanilla HUD |
| [`command`](./command) | client commands with typed argument slots |
| [`render`](./render) | world-space wireframe boxes, lines, and shapes |

### World

| Facade | Purpose |
| --- | --- |
| [`world`](./world) | time, dimension, weather, block and chunk queries |
| [`player`](./player) | the local player as a live handle, plus the open container |
| [`entity`](./entity) | entity lookup by UUID, type, and radius |

### Input

| Facade | Purpose |
| --- | --- |
| [`input`](./input) | keybind registration in the controls menu, key listening and injection |

### System

| Facade | Purpose |
| --- | --- |
| [`fs`](./fs) | sandboxed filesystem access relative to the game directory (capability-gated) |
| [`net`](./net) | HTTP client with `fetch` semantics (capability-gated) |
| [`java`](./java) | escape layer over the host JVM (permission-gated) |
| [`client`](./client) | client facts: FPS, game version, raw client entry |
| [`reflect`](./reflect) | exact-signature reflection over the escape layer (permission-gated) |

## Classes

Script-visible types handed to your code — live handles that read current
state, and immutable plain data. See the
[Classes index](./classes/entity) starting from
[`Entity`](./classes/entity), [`Player`](./classes/player),
[`ItemStack`](./classes/itemstack), [`Pos3D`](./classes/pos3d), or browse
any facade page: its signatures link to the types it uses.

## Events

49 client events across ten domains — [chat](./events/chat/chat-receive),
[player](./events/player/player-health), [entity](./events/entity/entity-load),
[world](./events/world/world-time), [input](./events/input/input-wheel),
[screen](./events/screen/screen-open), [tick](./events/tick/tick), and
[game](./events/game/game-start) lifecycle. Each event page lists its payload
fields; events that arrive at action boundaries can be cancelled to veto the
action.

## Version support

NeoMacros ships one build per supported Minecraft version (1.18.2 – 26.3).
The [version matrix](./version-matrix) maps every facade and every
version-constrained member to the builds it is available on.

[`neomacros.d.ts`](https://neomacros.tuanzi.ink/neomacros.d.ts) — drop it next to your scripts for
editor autocompletion.

New to NeoMacros? Start with the
[Getting Started guide](../guide/getting-started) or pick a complete script
from the [Examples](../examples/) section.

## Facades

### Core

| Facade | Purpose |
| --- | --- |
| [`events`](./modules/core/events) | EventEmitter-style subscription: `on` / `once` / `waitFor`, auto-cleanup on unload |
| [`thread`](./modules/core/thread) | timers, ticks, main-thread dispatch, per-script event loop |
| [`storage`](./modules/core/storage) | per-script persistent key-value store, JSON-serializable values |
| [`performance`](./modules/core/performance) | Web-Performance-style profiling: a session-anchored monotonic clock, User Timing marks and measures |

### UI

| Facade | Purpose |
| --- | --- |
| [`chat`](./modules/ui/chat) | send to server, local log lines, action bar messages |
| [`hud`](./modules/ui/hud) | persistent HUD text overlays above the vanilla HUD |
| [`command`](./modules/ui/command) | client commands with typed argument slots |
| [`render`](./modules/ui/render) | world-space wireframe boxes, lines, and shapes |
| [`screen`](./modules/ui/screen) | metadata about the currently open screen |

### World

| Facade | Purpose |
| --- | --- |
| [`world`](./modules/world/world) | time, dimension, weather, block and chunk queries |
| [`player`](./modules/world/player) | the local player as a live handle, plus the open container |
| [`entity`](./modules/world/entity) | entity lookup by UUID, type, and radius |

### Input

| Facade | Purpose |
| --- | --- |
| [`input`](./modules/input/input) | keybind registration in the controls menu, key listening and injection |

### System

| Facade | Purpose |
| --- | --- |
| [`fs`](./modules/system/fs) | sandboxed filesystem access relative to the game directory (capability-gated) |
| [`net`](./modules/system/net) | HTTP client with `fetch` semantics (capability-gated) |
| [`java`](./modules/system/java) | escape layer over the host JVM (permission-gated) |
| [`client`](./modules/system/client) | client facts: FPS, game version, raw client entry |
| [`reflect`](./modules/system/reflect) | exact-signature reflection over the escape layer (permission-gated) |

## Classes & types

Script-visible types handed to your code — live handles that read current
state, and immutable plain data. See the
[Classes index](./classes/entity) starting from
[`Entity`](./classes/entity), [`Player`](./classes/player),
[`ItemStack`](./classes/itemstack), [`Pos3D`](./classes/pos3d), or browse
any facade page: its signatures link to the types it uses.

Every event name maps to a payload class in the generated TypeScript
definitions, and the subscription methods resolve payload types per event
name. Payload classes share this group with the handles; start browsing
from [`BaseEvent`](./classes/baseevent).

## Events

49 client events across ten domains — [chat](./events/chat/chat-receive),
[player](./events/player/player-health), [entity](./events/entity/entity-load),
[world](./events/world/world-time), [input](./events/input/input-wheel),
[screen](./events/screen/screen-open), [tick](./events/tick/tick), and
[game](./events/game/game-start) lifecycle. Each event page lists its payload
fields and links to the payload class it dispatches; events that arrive at
action boundaries can be cancelled to veto the action.

## Version support

NeoMacros ships one build per supported Minecraft version (1.18.2 – 26.3).
The [version matrix](./version-matrix) maps every facade and every
version-constrained member to the builds it is available on.

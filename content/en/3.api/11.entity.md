# entity

The neo.entity facade: entity queries over the loaded world. Queries return live handles whose getters read current state in real time; a vanished entity reads back as undefined instead of raising.

Category: World · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.entity` and `@neomacros/entity`

**Classes**

[`Entity`](classes/entity) · [`ItemEntity`](classes/itementity) · [`LivingEntity`](classes/livingentity)

## Methods

### `inRadius(x: number, y: number, z: number, range: number)`

Returns handles of every entity within range blocks of the center point.

**Parameters**

- `x` `number`: 中心点坐标 X
- `y` `number`: 中心点坐标 Y
- `z` `number`: 中心点坐标 Z
- `range` `number`: 半径（格）

**Returns** `Array<`[Entity](classes/entity)`>`

Since: 0.1.0 · MC: * · Loader: *

### `lookup(uuid: string)`

Looks up a live entity handle by its UUID; undefined when absent or unloaded.

**Parameters**

- `uuid` `string`: 实体的 UUID 字符串

**Returns** [Entity](classes/entity)

Since: 0.1.0 · MC: * · Loader: *

### `nearest(x: number, y: number, z: number, range: number)`

Returns the nearest entity, or undefined when none matches.

**Parameters**

- `x` `number`: 中心点坐标 X
- `y` `number`: 中心点坐标 Y
- `z` `number`: 中心点坐标 Z
- `range` `number`: 半径（格）

**Returns** [Entity](classes/entity)

Since: 0.1.0 · MC: * · Loader: *

### `players()`

Returns handles of every loaded player in the world.

**Returns** `Array<`[Entity](classes/entity)`>`

Since: 0.1.0 · MC: * · Loader: *


## Examples

Find the nearest entity, resolve it again by UUID, and list every loaded player — all as live handles.

```js
const { entity } = neo;

// Nearest entity within 16 blocks of a point (undefined when none)
const mob = entity.nearest(128, 64, -212, 16);
if (mob) {
  // Live handle: pos, name and type re-read the world on every access
  const uuid = mob.uuid; // persist the uuid, find it again later
  const same = entity.lookup(uuid); // undefined once the entity is gone
}

// All loaded players, as live handles
const names = entity.players().map((p) => p.name);
```

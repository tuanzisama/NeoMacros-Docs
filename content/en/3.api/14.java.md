# java

The neo.java facade: the escape layer over the host JVM. Class lookup uses binary names (Mojmap for Minecraft classes, translated at the call site by the mapping layer); every capability of this module requires the java permission — granting it hands the script full host access with no class filtering. Construction happens through the class proxy's new(...) member; results wrap as object proxies whose members reach unwrapped Java fields and methods.

Category: System · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.java` and `@neomacros/java`

## Examples

Reach into the host JVM — this requires the java permission; class proxies expose statics directly and construct through new(...).

```js
const { java } = neo;

// Requires the java permission: full host JVM access, no class filtering
const UUID = java.type('java.util.UUID');
const token = UUID.randomUUID().toString(); // statics dispatch directly

const ArrayList = java.type('java.util.ArrayList');
const list = ArrayList.new(); // construct through the new(...) member
list.add('torch'); // instance methods via the object proxy
```

# thread

The neo.thread facade: thread introspection, time-based and main-thread asynchronous primitives, and timers, each bound to the calling script's context event loop. Every scheduling function returns a promise or a cancellable timer handle.

Category: Core · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.thread` and `@neomacros/thread`

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `main` | `boolean` | Whether the calling code is currently running on the game main thread. |

## Examples

Debounce a burst of calls into one delayed run, and pause an async flow in real time.

```js
const { thread } = neo;

let scheduled = false;

// Debounce: collapse a burst of calls into one delayed run
function request() {
  if (scheduled) return;
  scheduled = true;
  thread.after(250, () => {
    scheduled = false; // do the coalesced work here
  });
}

request(); // schedules the run 250 ms out
await thread.sleep(5000); // timers double as promises
```

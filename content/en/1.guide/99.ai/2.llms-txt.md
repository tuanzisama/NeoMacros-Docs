The documentation is also published as plain text for large language models. Both files are generated from the same content source as the pages, so they regenerate together with the site.

## The two files

- [llms.txt](https://neomacros.tuanzi.ink/llms.txt) is an index of the whole site: one entry per page with its title, a one-line description, and a link to the raw markdown version. The sections cover both languages (`Docs En` and `Docs Zh Cn`), plus the landing page and the full-text collection.
- [llms-full.txt](https://neomacros.tuanzi.ink/llms-full.txt) merges the complete text of every page into a single file of roughly 900 KB — the one to attach when the whole documentation goes into an agent's context.

## Raw page markdown

Every page exists as plain markdown under `/raw/<locale>/`, mirroring the site paths: the getting-started guide lives at [raw/en/guide/getting-started.md](https://neomacros.tuanzi.ink/raw/en/guide/getting-started.md), and its Chinese twin at [raw/zh-cn/guide/getting-started.md](https://neomacros.tuanzi.ink/raw/zh-cn/guide/getting-started.md). A page fetched this way arrives without navigation or scripts — just the text.

## Using it with an agent

An agent with web access needs only the index URL; a prompt such as *"read https://neomacros.tuanzi.ink/llms.txt and find the pages about storage"* resolves through the index to the right raw markdown. An agent that fetches a single file gets the whole documentation from llms-full.txt in one request.

The [MCP agent server](./mcp-server) complements these files with a live channel — the text files describe the API, while the MCP server lets an agent inspect and drive a running client.

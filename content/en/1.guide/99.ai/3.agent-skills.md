The site publishes two Agent Skills — packaged instruction sets that coding agents load when a task matches their description. They carry the same API facts as the documentation, in a form an agent can install on its own.

## The two skills

- **neomacros-scripting** covers writing, editing, and debugging scripts: the manifest format, event subscription, timers and threading, storage, HUD text, client commands, permissions, and the common failure modes.
- **neomacros-api** is the lookup companion: facade modules, class members, exact camelCase event names, payload fields, and version availability — the facts that keep an agent from inventing API members that do not exist.

Each skill is an English `SKILL.md` plus Chinese `references/` files, published under `/.well-known/skills/` on this domain.

## Installing

Agents that support the skills convention install both skills straight from the site:

```bash
npx skills add https://neomacros.tuanzi.ink
```

## Skills and the MCP server

The two integrations reach different things. A skill is static knowledge — how the API works — loaded into the agent's context when relevant. The [MCP agent server](./mcp-server) is a live channel into a running client: logs, game state, and control. For writing a script, the skills supply the facts; for checking what a script actually did on a running game, the MCP server answers.

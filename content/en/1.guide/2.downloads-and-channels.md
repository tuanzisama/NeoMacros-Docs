---
title: "Downloads & Channels"
---

NeoMacros ships four build channels. The channel is part of the version
string — in the file name and inside the jar — so you can always tell what
an installed copy is, and the in-game update checker compares against the
matching channel.

## Naming

| Channel | File name example (26.3 node) | Who it is for |
| --- | --- | --- |
| release | `neomacros-26.3-fabric-0.1.0.jar` | everyone; tagged, stable versions |
| dev | `neomacros-26.3-fabric-0.1.0-dev.123+abc1234.jar` | early adopters; rebuilt on every `main` push |
| canary | `neomacros-26.3-fabric-0.1.0-canary.45+def5678.jar` | testers; on-demand experimental builds |
| local | `neomacros-26.3-fabric-0.1.0-local.jar` | developers compiling from source |

How to read a dev/canary name: `0.1.0` is the baseline version,
`-dev.123` the channel plus CI build number (higher = newer), `+abc1234`
the commit the build was made from. The Minecraft version is always the
segment right after `neomacros-` — download the file whose segment matches
your game (e.g. `26.3` for Minecraft 26.3).

## Where to download

- **release**: the [releases page](https://github.com/tuanzisama/NeoMacros/releases);
  pick the latest non-prerelease and the jar matching your game version.
- **dev**: the rolling [`dev` tag](https://github.com/tuanzisama/NeoMacros/releases/tags/dev)
  — one page, always the newest build; older assets are replaced on every publish.
- **canary**: the rolling [`canary` tag](https://github.com/tuanzisama/NeoMacros/releases/tags/canary),
  published on demand.

Every release also ships a `SHA256SUMS` file for verifying downloads.
GitHub is not always reachable from mainland China; the mod's update
checker accounts for this (see below), and the release jars are additionally
reachable through the update manifest served at
[neomacros.tuanzi.ink](https://neomacros.tuanzi.ink).

## Update checks

The mod checks for updates in its own channel by default (a dev build
watches the dev channel; local builds never auto-check). Newer versions
arrive as an in-game toast plus a chat card, and as a banner in connected
editor panels. Everything is configurable under settings → **Updates**:

- *Check for updates* — turn automatic checks on or off.
- *Check interval* — hours between checks.
- *Update channel* — `auto` follows the running build's channel, or pin
  `release`/`dev`/`canary` explicitly.
- Per-version control: click **ignore this version** in the chat card (or
  run `/neomacros update ignore`), undo with `/neomacros update clear-ignore`,
  and `/neomacros update check` forces a check any time.

Because `api.github.com` is unreliable in mainland China, the checker
fetches its data from `https://neomacros.tuanzi.ink/update/updates.json`
first (served with the docs site) and only falls back to the GitHub API.
The manifest lists each channel's newest version with per-game-version
download links and SHA-256 digests.

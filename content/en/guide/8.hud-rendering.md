# HUD and World Rendering

NeoMacros can draw over the game in two ways: text overlays pinned to the screen (`neo.hud`) and wireframe shapes pinned to world coordinates (`neo.render`). Both persist across frames until you remove them or the script unloads — you draw once, the game keeps showing it.

## Draw persistent text on the HUD

`hud.addText` takes a stable id, the text, a screen position in pixels, and an ARGB color:

```js
const { hud } = neo;

hud.addText('greeting', 'Hello, HUD!', 8, 8, 0xFFFFFFFF);   // opaque white
```

The id is the handle you use to manage the entry later — the same string in `removeText(id)` or `hud.textIds()`, which lists everything you currently have on screen.

Colors are ARGB integers: the first hex pair is alpha, then red, green, blue.

```js
0xFFFFFFFF   // opaque white
0xFF00FF00   // opaque green
0x80FFFFFF   // half-transparent white
```

## Update text by re-adding

There is no separate update call: calling `addText` again with an existing id replaces that entry in place. A typical update loop re-writes the same id every time the value changes:

```js
const { hud } = neo;

function showStatus(text) {
    hud.addText('status', text, 8, 20, 0xFF00FF00);
}

function hideStatus() {
    hud.removeText('status');
}
```

When a script unloads, its text entries go with it — no leaks across reloads.

## Draw shapes in the world

`neo.render` draws wireframe geometry at world coordinates on named layers:

```js
const { render, player } = neo;

export function startup() {
    const p = player.self;
    if (!p) return;

    const base = p.pos.floor();                   // the block the feet occupy
    render.drawBox('marker', base, base.withY(base.y + 1), 0xFF00FF00);
    render.drawLine('marker', base, base.withY(base.y + 2), 0xFFFFFF00);
}
```

`drawBox(layerId, min, max, color)` needs two opposite corners and `drawLine(layerId, from, to, color)` two endpoints, all as [Pos3D](../api/classes/pos3d) values — derive them from handles like `player.self.pos`, `world.blockAt(x, y, z).pos`, or a raycast hit, and reshape them with `floor()`, `withX/Y/Z()`, and `add()`. Shapes accumulate per layer; `render.clearLayer('marker')` wipes one layer, and `render.layerIds()` lists the layers holding shapes. Layers clear automatically when the script unloads.

## Update sparingly from tick

Screen and world overlays do not need redrawing every frame. Drive updates from a `tick` subscription with a guard so the expensive part runs rarely:

```js
const { events, hud, player } = neo;

let n = 0;

events.on('tick', () => {
    n += 1;
    if (n % 10 !== 0) return;          // work twice a second, not twenty

    const p = player.self;
    if (!p) return;                    // nothing to show outside a world

    const pos = p.pos;
    const text = `${pos.x.toFixed(0)} ${pos.y.toFixed(0)} ${pos.z.toFixed(0)}`;
    hud.addText('coords', text, 8, 8, 0xFFFFFFFF);
});
```

The early return costs almost nothing on the nineteen ticks it skips, and the id-based replace keeps the display correct without accumulating entries. Facade details: [hud](../api/hud) and [render](../api/render).

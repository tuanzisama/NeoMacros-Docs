NeoMacros: a different codebase, a new API surface. The jsmacros-compat
layer runs JsMacros-style code on `neo.*` with minimal changes; the native
API replaces the layer script by script, at each script's own pace.

| Page | What it covers |
| --- | --- |
| [Migrating from JsMacros](./migrating-from-jsmacros) | Compat layer installation, script layout, coverage, async surfaces, missing APIs, behavioral deviations, JsMacros → `neo.*` map |

::tip
Migration only. For NeoMacros evaluation without a JsMacros background,
[Getting Started](../guide/getting-started) is the entry point.
::

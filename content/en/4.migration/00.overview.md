---
title: "Migration Guide"
---

NeoMacros is a different codebase with a new API surface. The
jsmacros-compat layer keeps JsMacros-style code running as-is on top of
`neo.*`; when a script is ready to move over for good, the native API
takes its place.

| Page | What it covers |
| --- | --- |
| [Migrating from JsMacros](./migrating-from-jsmacros) | Installing the compat layer, adapting the script layout, what works out of the box, the `await` changes, missing APIs, behavioral differences, and the JsMacros → `neo.*` map |

::tip
This section covers migration only. For evaluating NeoMacros without
migrating, [Getting Started](../guide/getting-started) is the recommended
starting point; nothing in this section is required reading.
::

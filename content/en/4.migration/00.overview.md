---
title: "Migration Guide"
---

NeoMacros is a different codebase with a new API surface — but you don't
have to start over. The jsmacros-compat layer keeps JsMacros-style code
running as-is on top of `neo.*`, and the native API is there whenever you
are ready to move a script over for good.

| Page | What it covers |
| --- | --- |
| [Migrating from JsMacros](./migrating-from-jsmacros) | Installing the compat layer, adapting the script layout, what works out of the box, the `await` changes, missing APIs, behavioral differences, and the JsMacros → `neo.*` map |

::tip
Not migrating — just evaluating NeoMacros? Start at
[Getting Started](../guide/getting-started) instead; nothing in this
section is required reading.
::

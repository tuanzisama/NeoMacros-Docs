Every page in this section is a complete, runnable script folder: the
directory tree, the full `neomacro.yml` manifest, and the complete entry
`.js` file — no ellipses, no "left as an exercise". Drop the folder into
`config/neomacros/macros/`, run `/neomacros reload`, and it works. Every
API call used here is documented in the
[API Reference](../api/), so each walkthrough links to the pages that
explain the calls in detail.

| Example | Script type | What it demonstrates |
| --- | --- | --- |
| [Auto-greet & keyword responder](./1.chat-automation) | event macro | declaring `world:join` + `chat:receive` in `config.event.on`, dispatching on `payload.type`, reading a `ChatComponent` |
| [Live status HUD](./2.hud-overlay) | service | a `world` lifecycle service, throttled `tick` handling, `hud.addText` with stable ids, cleanup in `dispose()` |
| [Keybind toggle helper](./3.keybinds) | keypress macro and service | `config.keypress` with `default-key`, toggling state in module scope, programmatic `input.registerKeybind`, `input.set` |
| [Persistent damage stats](./4.persistent-state) | service | counting `player:damage`, `storage.put` on a debounce timer, a custom `/stats` command via `command.register` |

::tip
New to NeoMacros? Walk through the [first script guide](../guide/first-script)
first — these examples assume you know where `config/neomacros/` lives and
what `/neomacros reload` does.
::

Every page in this section is a complete, runnable script folder: the
directory tree, the full `neomacro.yml` manifest, and the complete entry
`.js` file — no ellipses, no "left as an exercise". A folder placed under
`config/neomacros/macros/` is picked up by `/neomacros reload`. Every
API call used here is documented in the
[API Reference](../api/), so each walkthrough links to the pages that
explain the calls in detail.

| Example | Script type | What it demonstrates |
| --- | --- | --- |
| [Auto-greet & keyword responder](./chat-automation) | event macro | declaring `world:join` + `chat:receive` in `config.event.on`, dispatching on `payload.type`, reading a `ChatComponent` |
| [Live status HUD](./hud-overlay) | service | a `world` lifecycle service, throttled `tick` handling, `hud.addText` with stable ids, cleanup in `dispose()` |
| [Keybind toggle helper](./keybinds) | keypress macro and service | `config.keypress` with `key_code`, toggling state in module scope, programmatic `input.registerKeybind`, `input.set` |
| [Persistent damage stats](./persistent-state) | service | counting `player:damage`, `storage.put` on a debounce timer, a custom `/stats` command via `command.register` |

::tip
These examples assume the ground covered by the
[first script guide](../guide/first-script) — where `config/neomacros/`
lives and what `/neomacros reload` does.
::

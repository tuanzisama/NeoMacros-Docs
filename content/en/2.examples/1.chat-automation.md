# Auto-Greet & Keyword Responder

One event macro that greets you once per world session and answers a chat
keyword with a rate limit — the canonical shape of an event-driven script:
declare events in the manifest, dispatch on the payload, keep state in
module scope.

## What it does

- On [world:join](../api/events/world/world-join), logs a local greeting
  (once per session, guarded by a module-level flag).
- On [chat:receive](../api/events/chat/chat-receive), watches for the
  phrase "hello bot" (case-insensitive) and replies in chat — at most once
  every 15 seconds, and never to its own messages.

## The script

```text
config/neomacros/
└── macros/
    └── event/
        └── chat-bot/
            ├── neomacro.yml
            └── index.js
```

`neomacro.yml`:

```yaml
name: chat-bot
version: 1.0.0
author: you
description: Greets you once per session and answers a keyword
config:
  event:
    on:
      - world:join
      - chat:receive
```

`index.js`:

```js
// Greets you once per world session and answers "hello bot" in chat.
const { chat } = neo;

const GREETING = "chat-bot is at your service. Say 'hello bot' and I answer.";
const REPLY = "hi! I'm chat-bot, a script running on NeoMacros.";
const KEYWORD = /hello bot/i;
const REPLY_COOLDOWN_MS = 15000;

let greeted = false;
let lastReplyAt = 0;

// Called once per declared event, with that event's payload.
export function startup(payload) {
    if (payload.type === "world:join") {
        greetOnce();
    } else if (payload.type === "chat:receive") {
        respond(payload.message);
    }
}

function greetOnce() {
    if (greeted) return;
    greeted = true;
    chat.log(GREETING);
    chat.actionbar("chat-bot ready");
}

function respond(component) {
    const text = plainText(component);
    if (!KEYWORD.test(text)) return;
    if (text === REPLY) return; // our own reply echoes back as chat:receive
    const now = Date.now();
    if (now - lastReplyAt < REPLY_COOLDOWN_MS) return;
    lastReplyAt = now;
    chat.say(REPLY);
}

// ChatComponent arrives as plain data: a text node with nested children.
function plainText(component) {
    if (!component || typeof component.text !== "string") return "";
    let text = component.text;
    const children = Array.isArray(component.children) ? component.children : [];
    for (const child of children) {
        text += plainText(child);
    }
    return text;
}
```

## How it works

**One startup, many events.** The manifest declares two events in
`config.event.on`, so `startup(payload)` is invoked once per firing of
either. Because the payload shapes differ, the script branches on
`payload.type` — every event payload carries the reserved
[`type`](../api/events) field holding the event name (`"world:join"`,
`"chat:receive"`, …). This is the standard pattern for a multi-event
macro; if your logic fits separate concerns better, split them into two
folders instead.

**The session guard.** Top-level code runs once at load, so `greeted`
starts `false` per load. Event macros live in `macros/event/` with a
`world` lifecycle by default: the mod loads them when a world session
opens — *before* `world:join` is published — and unloads them when it
closes. The flag therefore means exactly "once per session", and it
resets on the next join or on `/neomacros reload`.

**Reading the message.** `chat:receive` carries the message as a
`ChatComponent` — plain data with a `text` field and a `children` array
of nested nodes. `plainText` walks that tree defensively (the root text
plus every descendant) and returns one string, which is what the keyword
test and the echo check operate on.

**Two kinds of quiet.** [chat.log](../api/chat) renders only in your own
chat HUD, and `chat.actionbar` shows a temporary line above the hotbar —
neither reaches the server, which is why the greeting uses them. The
keyword reply is real automation, so it uses `chat.say` and pays for it
with two guards: the self-echo check (your own sent messages come back
through `chat:receive`) and the 15-second cooldown.

## Run it

1. Create the folder above under `.minecraft/config/neomacros/macros/event/`.
2. Run `/neomacros reload`, then `/neomacros list` to confirm `chat-bot` loaded.
3. Join any world — the greeting appears locally. Type `hello bot` in chat
   to trigger a reply; type it again immediately to see the cooldown hold.

::note
This macro needs no trust: `chat` is not capability-gated. Only `fs`,
`net`, `java`, and `command` calls ask for
[/neomacros trust](../guide/permissions-trust).
::

## Try extending

- Respond with the player's name: the message text usually starts with
  `<Name> ` on servers — slice it off and address the reply.
- Add more keywords: turn the single `KEYWORD` regex into a list of
  `{ pattern, reply }` pairs and pick the first match.
- Gate it per dimension: read [world.dimension](../api/world) in
  `respond` and reply only in `minecraft:overworld`.

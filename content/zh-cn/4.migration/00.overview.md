NeoMacros 是一套全新的代码库和全新的 API 表面——但你不必从零开始。
jsmacros-compat 兼容层让 JsMacros 风格的代码原样跑在 `neo.*` 之上；
等你准备好把某个脚本彻底搬过去时，原生 API 随时都在。

| 页面 | 内容 |
| --- | --- |
| [从 JsMacros 迁移](./migrating-from-jsmacros) | 安装兼容层、适配脚本目录结构、开箱即用的部分、需要补 `await` 的部分、缺失的 API、行为差异，以及 JsMacros → `neo.*` 对照表 |

::tip
不是迁移、只是来评估 NeoMacros 的？建议直接从[快速上手](../guide/getting-started)

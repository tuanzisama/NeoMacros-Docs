# 实时状态 HUD

一个服务脚本，在屏幕上维持一块三行状态面板：坐标与朝向、世界信息、
生命状态。这是实时悬浮层的标准形态——订阅 `tick`、加节流、读取活句柄，
再把文本以稳定 id 推入 [hud](../api/hud) 覆盖层。

## 它做什么

- 每秒两次（每 10 tick）刷新一块三行悬浮层：
  - 位置与朝向，来自本地玩家句柄；
  - 维度、天数与游戏内时钟，来自 [world](../api/world) 属性；
  - 生命值、饥饿值与 FPS。
- 离开世界（或在世界的间隙）时，移除这些文本项。

## 脚本

```text
config/neomacros/
└── macros/
    └── services/
        └── status-hud/
            ├── neomacro.yml
            └── index.js
```

`neomacro.yml`：

```yaml
name: status-hud
version: 1.0.0
author: you
description: Live position, world, and vitals overlay
config:
  service:
    lifecycle: world
    autostart: true
```

`index.js`：

```js
// A three-line status overlay refreshed twice per second.
const { events, hud, player, world, client } = neo;

const REFRESH_TICKS = 10; // update every 10 ticks: twice per second
const WHITE = 0xffffffff;
const GRAY = 0xffb4b4b4;
const GREEN = 0xff55ff55;

export function startup() {
    events.on("tick", (event) => {
        if (event.count % REFRESH_TICKS !== 0) return;
        refresh();
    });
}

async function refresh() {
    const self = player.self;
    if (!self) {
        await clearHud();
        return;
    }
    const pos = self.pos;
    await hud.addText("status-hud:coords",
        `XYZ ${pos.x.toFixed(1)} / ${pos.y.toFixed(1)} / ${pos.z.toFixed(1)}  (${self.facing})`,
        6, 6, WHITE);
    await hud.addText("status-hud:world",
        `${world.dimension.replace("minecraft:", "")} · day ${world.day} · ${clockText(world.time)}`,
        6, 18, GRAY);
    await hud.addText("status-hud:vitals",
        `HP ${self.health.toFixed(1)}/${self.maxHealth.toFixed(0)} · food ${self.hunger} · ${client.fps} fps`,
        6, 30, GREEN);
}

async function clearHud() {
    await hud.removeText("status-hud:coords");
    await hud.removeText("status-hud:world");
    await hud.removeText("status-hud:vitals");
}

// world.time is the time of day in ticks (0..24000); tick 0 is 06:00.
function clockText(timeOfDay) {
    const ticks = timeOfDay % 24000;
    const minutes = Math.floor((ticks % 1000) * 60 / 1000);
    const hours = Math.floor(ticks / 1000 + 6) % 24;
    return `${String(hours).padStart(2, "0")}:${String(minutes).padStart(2, "0")}`;
}

export async function dispose() {
    await clearHud();
}
```

## 工作原理

**节流。** `tick` 每个客户端 tick 触发一次——每秒 20 次——其
[tick 载荷](../api/events/tick/tick)带有可供过滤的 `count`。
一次取模判断后立即返回几乎零开销；而每个 tick 都重绘三条覆盖层文本就是
纯浪费。`tick % 10` 意味着面板每秒刷新两次，对文本来说绰绰有余。
订阅 `tick` 时务必带上过滤或立刻返回的短路判断。

**稳定 id。** `hud.addText(id, text, x, y, color)` 按 `id` 注册一条持久
文本项，重复添加同一 id 会直接替换。这正是更新廉价的原因：脚本始终写入
同样三个 id（`status-hud:coords`、`:world`、`:vitals`），固定像素位置，
既不累积也不闪烁。每行是独立的一项——一行一个 id，几何布局完全由你掌控。

**活句柄。** `player.self` 是一个活的 [LocalPlayer](../api/classes/localplayer)
句柄：每次属性读取（`pos`、`facing`、`health`、`maxHealth`、`hunger`）
都实时读取当前游戏状态，无需缓存。不在世界时它读取为 `undefined`——
`if (!self)` 分支会清空文本项，而不是把 `undefined` 画到屏幕角落。

**清理。** 覆盖层文本项跨帧保留，直到被移除或模块卸载，所以仅凭卸载
也能清理。但显式的 [`dispose()`](../guide/first-script) 导出仍然调用了
`clearHud()`：它在重载时执行，把移除变得明确而即时——对任何悬浮层脚本
都是好习惯。

## 运行

1. 在 `.minecraft/config/neomacros/macros/services/` 下创建上述文件夹。
2. 执行 `/neomacros reload`。清单设置了
   `config.service.autostart: true` 与 `lifecycle: world`，因此进入世界时
   服务会自动拉起，无需手动启动。
3. 进入世界，看屏幕左上角。离开再进入，可以观察到文本项被移除又重绘。

::tip
颜色是 ARGB 数字：`0xffffffff` 为不透明白色，`0xffb4b4b4` 为暗灰色。
把 alpha 字节降到 `0x80...` 可获得半透明效果。
::

## 尝试扩展

- 低血量警告：当 `self.health` 低于 6 时，把状态行改用红色
  （`0xffff5555`）重绘而非绿色。
- 显示生物群系：用 `pos.floor()` 得到的坐标调用
  [world.biomeAt](../api/world)，把群系标识追加到世界行。
- 界面打开时暂停：订阅 [screen:open](../api/events/screen/screen-open)
  与 `screen:close`，容器界面打开时跳过刷新。

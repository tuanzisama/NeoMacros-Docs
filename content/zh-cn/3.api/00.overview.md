TypeScript 用户可以直接使用完整的类型定义
[`neomacros.d.ts`](https://neomacros.tuanzi.ink/neomacros.d.ts)——把它放在脚本旁边即可获得编辑器
自动补全。

第一次接触 NeoMacros？从[快速上手](../guide/getting-started)开始，或到
[示例](../examples/)区挑一个完整脚本。

## 门面

### 核心

| 门面 | 用途 |
| --- | --- |
| [`events`](./modules/core/events) | EventEmitter 风格订阅：`on` / `once` / `waitFor`，卸载时自动清理 |
| [`thread`](./modules/core/thread) | 定时器、tick 调度、主线程派发，每个脚本独立事件循环 |
| [`storage`](./modules/core/storage) | 按脚本隔离的持久化键值存储，值需可 JSON 序列化 |
| [`performance`](./modules/core/performance) | Web Performance 风格的宏性能分析：锚定会话起点的单调时钟与 User Timing 标记、测量 |

### 界面

| 门面 | 用途 |
| --- | --- |
| [`chat`](./modules/ui/chat) | 发送到服务器、本地聊天行、动作栏消息 |
| [`hud`](./modules/ui/hud) | 原版 HUD 之上的持久文本覆盖层 |
| [`command`](./modules/ui/command) | 带类型化参数槽的客户端命令注册 |
| [`render`](./modules/ui/render) | 世界空间线框盒子、线条与形状 |
| [`screen`](./modules/ui/screen) | 当前打开屏幕的元信息（自建 GUI 属后续阶段） |

### 世界

| 门面 | 用途 |
| --- | --- |
| [`world`](./modules/world/world) | 时间、维度、天气、方块与区块查询 |
| [`player`](./modules/world/player) | 本地玩家实时句柄，以及当前打开的容器 |
| [`entity`](./modules/world/entity) | 按 UUID、类型、半径查询实体 |

### 输入

| 门面 | 用途 |
| --- | --- |
| [`input`](./modules/input/input) | 在控制设置中注册按键绑定，按键监听与注入 |

### 系统

| 门面 | 用途 |
| --- | --- |
| [`fs`](./modules/system/fs) | 相对游戏目录的沙箱文件访问（需能力授权） |
| [`net`](./modules/system/net) | 语义同 `fetch` 的 HTTP 客户端（需能力授权） |
| [`java`](./modules/system/java) | 宿主 JVM 的逃逸层（需权限授予） |
| [`client`](./modules/system/client) | 客户端事实：FPS、游戏版本、raw 客户端入口 |
| [`reflect`](./modules/system/reflect) | 逃逸层之上的精确签名反射（需权限授予） |

## 类与类型

脚本可见的类型——读取实时状态的活句柄（handle）与不可变的纯数据
（data）。可以从 [`Entity`](./classes/entity)、[`Player`](./classes/player)、
[`ItemStack`](./classes/itemstack)、[`Pos3D`](./classes/pos3d) 进入浏览，
也可以打开任意门面页面：它的签名都链接到用到的类型。

每个事件名都对应生成 TypeScript 定义中的一个载荷类，订阅方法按事件名解析
载荷类型。载荷类与句柄类同组展示，从 [`BaseEvent`](./classes/baseevent)
进入浏览。

## 事件

覆盖十个域共 49 个客户端事件——[聊天](./events/chat/chat-receive)、
[玩家](./events/player/player-health)、[实体](./events/entity/entity-load)、
[世界](./events/world/world-time)、[输入](./events/input/input-wheel)、
[界面](./events/screen/screen-open)、[tick](./events/tick/tick) 与
[游戏](./events/game/game-start)生命周期。每个事件页列出载荷字段，并链接到
它分发的载荷类；到达动作边界的事件可以取消，从而否决该动作。

## 版本支持

NeoMacros 为每个受支持的 Minecraft 版本（1.18.2 – 26.3）发布独立构建。
[版本兼容矩阵](./version-matrix)列出了每个门面和每个带版本限制成员的
可用构建。

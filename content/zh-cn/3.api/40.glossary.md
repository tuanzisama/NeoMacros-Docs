API 参考围绕一组反复出现的概念展开。下面的词条注明了术语在生成页面上的
出现位置，遇到不认识的徽章或胶囊时可以随时回到本页查阅。

## 类与值

### 句柄 (Handle)

对游戏对象的活引用。句柄的属性读取器在每次访问时实时查询游戏状态，所以
实体消失后再读取会返回 `undefined` 而不是抛错。调用句柄的 `snapshot()`
可以把当前值冻结成一份普通 record（[Entity](./classes/entity) →
[EntitySnapshot](./classes/entitysnapshot)）。类页面的声明框会用
`句柄` 胶囊标记句柄类型；其他例子还有
[Player](./classes/player) 和 [FileHandle](./classes/filehandle)。

### 数据 (Data)

不可变的纯数据类——坐标、方块、物品堆、文本。数据值不会在你眼皮底下
变化，且可以安全 JSON 序列化，可随意存储、比较、传递。与句柄相对：
句柄的读取永远反映"现在"的世界状态。
例子：[Pos2D](./classes/pos2d)、[BlockPos](./classes/blockpos)、
[ItemStack](./classes/itemstack)、[Text](./classes/text)。

### 记录 (Record)

以字段表形式渲染的纯复合类型——没有方法，没有活状态。记录主要出现在
签名和事件载荷中：[EntitySnapshot](./classes/entitysnapshot) 和
[Pos3d](./classes/pos3d) 都是记录。类页面会用 `记录` 胶囊标记。

## 事件

### 事件 (Event)

脚本可以通过[事件门面](./modules/core/events)订阅的游戏侧发生的事情
（`on` / `once` / `waitFor`）。事件名是驼峰式并按域分组，例如
`player:attackBlock`。每个事件页都列出载荷与是否可取消；脚本卸载时
订阅会自动清理。

### 载荷 (Payload)

处理器收到的冻结事件对象——一个
`…Event extends [BaseEvent](./classes/baseevent)` 实例，事件细节都在
其字段上。载荷字段只读；每个载荷在侧栏的"类与类型"分组里有独立页面，
例如 [ChatSendEvent](./classes/chatsendevent)。

### 可取消 (Cancellable)

可以否决的事件会带此徽章：处理器返回真值的 `cancel` 即可阻止原版行为
（拦截聊天发送、攻击等）。不可取消的事件无论如何都会发生。

## 模块与暴露

### 门面模块 (Facade module)

一个域的脚本可见接口——`chat`、`world`、`hud` 等——每个门面一页生成
文档，按类别归入侧栏的模块树，例如 [chat](./modules/ui/chat)。门面是
脚本接触游戏的唯一途径，一切能力都挂在门面上。

### 全局对象 (Global object)

每个门面同时以 `neo.<模块>` 形式暴露在全局对象上，最简单的脚本完全
不需要 import——`neo.chat.log("hi")`。全部脚本可见类也直接挂在同一根
上（`neo.Entity`、`neo.Pos3D`）。配合 [`neomacros.d.ts`](/neomacros.d.ts)
获得编辑器自动补全。

## 可用性与徽章

### 可用性胶囊

每个模块和成员都带三个胶囊：**NeoMacro**（引入该成员的发布版本）、
**Minecraft**（版本可用性表达式，见下）、**Fabric Loader**。
`*` 表示"全部"。

### MC 版本表达式

Minecraft 胶囊背后的值（模组侧的 `@ApiMC` 注解）：`*` 表示全版本，
比较式如 `>=1.20.6`，闭区间如 `1.18-1.21`，或精确版本号。
[版本兼容性](./version-matrix)页面把每个表达式对每个受支持构建求值。

### 只读 (Read-only)

属性徽章：该属性观察的状态不能从脚本赋值（实体的 `eyePos`、按键绑定
的按键等）。

### 实验性 (Experimental)

徽章警示该成员可能在版本之间变化或移除——能用，但不承诺稳定。

### 权限 (Permission)

文件系统、网络、JVM 互操作、反射等逃逸层都运行在信任系统之后；权限
胶囊标明脚本所需的授权。参见[权限与信任指南](../guide/permissions-trust)。

## 平台背景

### GraalJS

Oracle GraalVM 的 JavaScript 引擎。NeoMacros 把它内嵌为客户端的脚本
运行时，因此脚本既保持普通 JavaScript 形态，又能（通过上述受控逃逸层）
与真实 Java 对象互传值。

### Fabric

NeoMacros 发布所依赖的轻量模组加载器生态。**Fabric Loader** 胶囊追踪
模组构建所对的加载器版本；NeoMacros 本身是一个 Fabric 客户端模组。

### 一个版本一个构建

NeoMacros 为每个受支持的 Minecraft 版本发布独立 jar，因为它绑定的
客户端内部实现随版本变动。模组构建用 Stonecutter 编排同一份源码在全部
版本上的编译；[版本兼容性](./version-matrix)页面就是产出的兼容矩阵。

### `neomacros.d.ts`

镜像整个生成 API 的 TypeScript 定义文件——放在脚本旁边即可获得编辑器
自动补全与类型检查。从 [`/neomacros.d.ts`](/neomacros.d.ts) 下载当前
构建的版本。

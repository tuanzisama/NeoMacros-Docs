# entity

neo.entity 门面：对已加载世界的实体查询。查询返回活句柄，属性实时回读当前状态；实体消失后属性回读为 undefined 而不报错。

Category: 世界 · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.entity` and `@neomacros/entity`

**Classes**

[`Entity`](classes/entity) · [`ItemEntity`](classes/itementity) · [`LivingEntity`](classes/livingentity)

## Methods

### `inRadius(x: number, y: number, z: number, range: number)`

查询中心点半径范围内的全部实体句柄。

**Parameters**

- `x` `number`: 中心点坐标 X
- `y` `number`: 中心点坐标 Y
- `z` `number`: 中心点坐标 Z
- `range` `number`: 半径（格）

**Returns** `Array<`[Entity](classes/entity)`>` — 实体句柄数组

Since: 0.1.0 · MC: * · Loader: *

### `lookup(uuid: string)`

按 UUID 查询实体句柄；不存在或已卸载时为 undefined。

**Parameters**

- `uuid` `string`: 实体的 UUID 字符串

**Returns** [Entity](classes/entity) — 实体句柄，或 undefined

Since: 0.1.0 · MC: * · Loader: *

### `nearest(x: number, y: number, z: number, range: number)`

返回距离中心最近的实体句柄；无命中时为 undefined。

**Parameters**

- `x` `number`: 中心点坐标 X
- `y` `number`: 中心点坐标 Y
- `z` `number`: 中心点坐标 Z
- `range` `number`: 半径（格）

**Returns** [Entity](classes/entity) — 最近实体句柄或 undefined

Since: 0.1.0 · MC: * · Loader: *

### `players()`

返回世界中全部玩家的句柄。

**Returns** `Array<`[Entity](classes/entity)`>` — 玩家句柄数组

Since: 0.1.0 · MC: * · Loader: *


## Examples

实体查询返回活句柄：找最近实体、按 UUID 回查、列出所有已加载玩家。

```js
const { entity } = neo;

// Nearest entity within 16 blocks of a point (undefined when none)
const mob = entity.nearest(128, 64, -212, 16);
if (mob) {
  // Live handle: pos, name and type re-read the world on every access
  const uuid = mob.uuid; // persist the uuid, find it again later
  const same = entity.lookup(uuid); // undefined once the entity is gone
}

// All loaded players, as live handles
const names = entity.players().map((p) => p.name);
```

# command

neo.command 门面：客户端命令注册与派发。命令以声明式注册，经 command.arg 构建带类型的参数槽（int() float() bool() word() string() greedy() player() pos()，另有 optional() 与 default(v)）；处理器收到的上下文 args 携带解析值，raw 保留剩余字符串。

Category: 界面 · Since: 0.1.0 · MC availability: * · Loader availability: * · Exposed as `neo.command` and `@neomacros/command`

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `arg` | `CommandArgFactory` | 带类型的参数槽工厂（command.arg）。 (read-only) |

## Examples

注册带类型参数槽的客户端命令，并以玩家身份派发另一条命令（register 与 execute 需要 command 权限）。

```js
const { command } = neo;

// register/execute both require the 'command' permission
command.register({
  name: 'mine',
  description: 'Announce a mining route',
  args: {
    ore: command.arg.word(), // required word slot
    seconds: command.arg.int().optional(),
  },
  handler(ctx) {
    // ctx.args: parsed values (ctx.args.ore); ctx.raw: the remainder string
  },
});

await command.execute('/neomacros list'); // dispatch as if typed
```

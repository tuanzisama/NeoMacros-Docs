# API 参考

脚本可以触及的一切都挂在全局 `neo` 对象上——共 16 个门面，每个同时可以
作为 ES 模块导入（`@neomacros/chat`、`@neomacros/world`……）。本节页面
由文档管线在每次 API 变更时从模组源码的注解生成，始终与运行中的模组
保持一致。

TypeScript 用户可以直接使用完整的类型定义
[`neomacros.d.ts`](/neomacros.d.ts)——把它放在脚本旁边即可获得编辑器
自动补全。

第一次接触 NeoMacros？从[快速上手](../guide/getting-started)开始，或到
[示例](../examples/)区挑一个完整脚本。

## 门面

### 核心

| 门面 | 用途 |
| --- | --- |
| [`events`](./events) | EventEmitter 风格订阅：`on` / `once` / `waitFor`，卸载时自动清理 |
| [`thread`](./thread) | 定时器、tick 调度、主线程派发，每个脚本独立事件循环 |
| [`storage`](./storage) | 按脚本隔离的持久化键值存储，值需可 JSON 序列化 |

### 界面

| 门面 | 用途 |
| --- | --- |
| [`chat`](./chat) | 发送到服务器、本地聊天行、动作栏消息 |
| [`hud`](./hud) | 原版 HUD 之上的持久文本覆盖层 |
| [`command`](./command) | 带类型化参数槽的客户端命令注册 |
| [`render`](./render) | 世界空间线框盒子、线条与形状 |

### 世界

| 门面 | 用途 |
| --- | --- |
| [`world`](./world) | 时间、维度、天气、方块与区块查询 |
| [`player`](./player) | 本地玩家实时句柄，以及当前打开的容器 |
| [`entity`](./entity) | 按 UUID、类型、半径查询实体 |

### 输入

| 门面 | 用途 |
| --- | --- |
| [`input`](./input) | 在控制设置中注册按键绑定，按键监听与注入 |

### 系统

| 门面 | 用途 |
| --- | --- |
| [`fs`](./fs) | 相对游戏目录的沙箱文件访问（需能力授权） |
| [`net`](./net) | 语义同 `fetch` 的 HTTP 客户端（需能力授权） |
| [`java`](./java) | 宿主 JVM 的逃逸层（需权限授予） |
| [`client`](./client) | 客户端事实：FPS、游戏版本、raw 客户端入口 |
| [`reflect`](./reflect) | 逃逸层之上的精确签名反射（需权限授予） |

## 类

脚本可见的类型——读取实时状态的活句柄（handle）与不可变的纯数据
（data）。可以从 [`Entity`](./classes/entity)、[`Player`](./classes/player)、
[`ItemStack`](./classes/itemstack)、[`Pos3D`](./classes/pos3d) 进入浏览，
也可以打开任意门面页面：它的签名都链接到用到的类型。

## 事件

覆盖十个域共 49 个客户端事件——[聊天](./events/chat/chat-receive)、
[玩家](./events/player/player-health)、[实体](./events/entity/entity-load)、
[世界](./events/world/world-time)、[输入](./events/input/input-wheel)、
[界面](./events/screen/screen-open)、[tick](./events/tick/tick) 与
[游戏](./events/game/game-start)生命周期。每个事件页列出载荷字段；
到达动作边界的事件可以取消，从而否决该动作。

## 版本支持

NeoMacros 为每个受支持的 Minecraft 版本（1.18.2 – 26.3）发布独立构建。
[版本兼容矩阵](./version-matrix)列出了每个门面和每个带版本限制成员的
可用构建。

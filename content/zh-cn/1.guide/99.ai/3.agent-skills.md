站点发布两个 Agent Skills——打包好的指令集，编码类 Agent 在任务与其描述匹配时加载。它们携带与文档一致的 API 事实，形式上 Agent 可以自行安装。

## 两个技能

- **neomacros-scripting** 覆盖脚本的编写、修改与排错：清单格式、事件订阅、定时器与线程、存储、HUD 文本、客户端命令、权限，以及常见故障模式。
- **neomacros-api** 是配套的查阅卷：门面模块、类成员、精确的驼峰事件名、载荷字段与版本支持——这些事实防止 Agent 编造不存在的 API 成员。

每个技能是一份英文的 `SKILL.md` 加中文的 `references/` 文件，发布在本域名的 `/.well-known/skills/` 路径下。

## 安装

支持 skills 约定的 Agent 直接从站点安装两个技能：

```bash
npx skills add https://neomacros.tuanzi.ink
```

## 与 MCP 服务器的分工

两种接入触及的范围不同。技能是静态知识——API 如何工作——在相关时进入 Agent 的上下文。[MCP Agent 服务器](./mcp-server)是进入运行中客户端的实时通道：日志、游戏状态与控制。写脚本时，技能供给事实；确认脚本在运行中的游戏里实际做了什么，由 MCP 服务器回答。

文档站同时以纯文本形式发布，供大语言模型读取。两份文件与页面出自同一内容源，站点更新时一并再生。

## 两份文件

- [llms.txt](https://neomacros.tuanzi.ink/llms.txt) 是全站的索引：每页一条，含标题、一句话描述和对应原始 markdown 的链接。分区覆盖中英两种语言（`Docs En` 与 `Docs Zh Cn`），另有落地页和全文合集。
- [llms-full.txt](https://neomacros.tuanzi.ink/llms-full.txt) 把全部页面的完整文本合并成一个约 900 KB 的文件——需要把整站文档放进 Agent 上下文时，附带这一份。

## 页面的原始 markdown

每个页面在 `/raw/<语言>/` 下都有对应的纯 markdown 版本，路径与站点一致：快速上手在 [raw/en/guide/getting-started.md](https://neomacros.tuanzi.ink/raw/en/guide/getting-started.md)，中文版在 [raw/zh-cn/guide/getting-started.md](https://neomacros.tuanzi.ink/raw/zh-cn/guide/getting-started.md)。这样取到的单页没有导航和脚本，只有正文。

## 配合 Agent 使用

能访问网络的 Agent 只需要索引地址；类似下方的提示会顺着索引落到正确的原始 markdown。一次只能取一个文件的 Agent，用 llms-full.txt 一个请求就能覆盖全部内容。

```
读一下 https://neomacros.tuanzi.ink/llms.txt ，找到讲存储的页面
```

[MCP Agent 服务器](./mcp-server)在这些文件之外提供实时通道——文本文件描述 API，MCP 服务器让 Agent 读取并驱动一个运行中的客户端。

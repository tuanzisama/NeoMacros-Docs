# HUD 与渲染

NeoMacros 有两种方式叠画到游戏上：钉在屏幕上的文本覆盖层（`neo.hud`），和钉在世界坐标上的线框图形（`neo.render`）。两者都会跨帧保留，直到你移除它们或脚本卸载——画一次，游戏会一直显示。

## 在 HUD 上绘制持久文本

`hud.addText` 接受一个稳定 id、文本、以像素为单位的屏幕位置和 ARGB 颜色：

```js
const { hud } = neo;

hud.addText('greeting', 'Hello, HUD!', 8, 8, 0xFFFFFFFF);   // opaque white
```

这个 id 就是你日后管理该条目的句柄——在 `removeText(id)` 里传同一个字符串即可，`hud.textIds()` 则会列出当前屏幕上的所有条目。

颜色是 ARGB 整数：第一对十六进制位是 alpha，其后依次是红、绿、蓝。

```js
0xFFFFFFFF   // opaque white
0xFF00FF00   // opaque green
0x80FFFFFF   // half-transparent white
```

## 通过重新添加来更新文本

没有单独的更新调用：用已有的 id 再次调用 `addText`，会原地替换该条目。典型的更新循环在值每次变化时重写同一个 id：

```js
const { hud } = neo;

function showStatus(text) {
    hud.addText('status', text, 8, 20, 0xFF00FF00);
}

function hideStatus() {
    hud.removeText('status');
}
```

脚本卸载时，它的文本条目也随之消失——重载之间不会泄漏。

## 在世界里绘制图形

`neo.render` 在命名图层上按世界坐标绘制线框几何：

```js
const { render, player } = neo;

export function startup() {
    const p = player.self;
    if (!p) return;

    const base = p.pos.floor();                   // the block the feet occupy
    render.drawBox('marker', base, base.withY(base.y + 1), 0xFF00FF00);
    render.drawLine('marker', base, base.withY(base.y + 2), 0xFFFFFF00);
}
```

`drawBox(layerId, min, max, color)` 需要两个对角点，`drawLine(layerId, from, to, color)` 需要两个端点，都以 [Pos3D](../api/classes/pos3d) 值传入——从 `player.self.pos`、`world.blockAt(x, y, z).pos` 或射线命中的结果之类的句柄取值，再用 `floor()`、`withX/Y/Z()` 和 `add()` 对它们做变形。图形按图层累积；`render.clearLayer('marker')` 清空一个图层，`render.layerIds()` 列出所有持有图形的图层。脚本卸载时图层会自动清空。

## 从 tick 节制地更新

屏幕和世界覆盖层不需要每帧重画。用带防护的 `tick` 订阅驱动更新，让高开销的部分少跑：

```js
const { events, hud, player } = neo;

let n = 0;

events.on('tick', () => {
    n += 1;
    if (n % 10 !== 0) return;          // work twice a second, not twenty

    const p = player.self;
    if (!p) return;                    // nothing to show outside a world

    const pos = p.pos;
    const text = `${pos.x.toFixed(0)} ${pos.y.toFixed(0)} ${pos.z.toFixed(0)}`;
    hud.addText('coords', text, 8, 8, 0xFFFFFFFF);
});
```

提前返回在被跳过的十九个 tick 上几乎没有开销，基于 id 的替换让显示保持正确且不累积条目。门面细节见 [hud](../api/modules/ui/hud)和 [render](../api/modules/ui/render)。

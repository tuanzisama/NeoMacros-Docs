# 快速上手

NeoMacros 是一个客户端 Fabric 模组，能在你的 Minecraft 游戏内运行 ECMAScript（JavaScript）。脚本就是普通的 `.js` ES 模块，由 GraalJS 直接执行——真正的 promise、`async`/`await`，每个脚本还拥有独立的事件循环。无需转译，无需构建，把文件放进文件夹就能跑。

## 检查环境要求

安装前需要准备四样东西：

- **Minecraft**（客户端），版本需在 NeoMacros 的构建范围内。发布版覆盖很宽的区间，从 1.18.2 一直到 26.x 系列。
- 为该游戏版本安装的 **Fabric Loader**。
- 与游戏版本匹配的 **Fabric API**。
- **NeoMacros 的 jar** 本体，从[发布页](https://github.com/tuanzisama/NeoMacros/releases)下载。文件名形如 `neomacros-<mc>-fabric-<version>.jar`——挑选 Minecraft 版本与你一致的那个构建。

## 安装模组

1. 如果还没装，先为你的 Minecraft 版本安装 Fabric Loader。
2. 把 NeoMacros 的 jar 和匹配的 Fabric API jar 放进 `mods` 文件夹。
3. 启动一次游戏。NeoMacros 会在 `config/neomacros/` 创建自己的工作目录，并在 `config/neomacros/macros/` 创建脚本根目录。

## 了解目录结构

脚本相关的所有内容都在游戏目录之下：

```text
.minecraft/
└── config/
    └── neomacros/
        ├── config.json    # mod settings, including trust decisions
        └── macros/        # your scripts, one folder per script
            ├── keypress/  # scripts bound to key presses
            ├── event/     # scripts driven by declared game events
            └── services/  # long-running background scripts
```

每个脚本文件夹里放一份 `neomacro.yml` 清单（或 `neomacro.json`）和入口文件。类别目录决定脚本的触发方式：`keypress` 脚本在按键沿触发，`event` 脚本在其声明的事件上触发，`service` 则启动一次并自行保持存活。

## 用客户端命令管理脚本

四条客户端命令覆盖了整个管理工作流：

| 命令 | 用途 |
| --- | --- |
| `/neomacros list` | 列出当前已加载的脚本 |
| `/neomacros reload` | 重新扫描 macros 文件夹并应用你的改动 |
| `/neomacros trust <script>` | 给脚本授予它所声明的能力 |
| `/neomacros errors` | 打开列出近期脚本错误的界面 |

日常反复使用的编辑循环是：保存文件，执行 `/neomacros reload`，观察结果。

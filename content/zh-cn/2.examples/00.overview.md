title: "示例"
---

本节每一页都是一个完整、可直接运行的脚本文件夹：包含目录树、完整的
`neomacro.yml` 清单和完整的入口 `.js` 文件——没有省略号，也没有"留作练习"。
把文件夹放进 `config/neomacros/macros/`，执行 `/neomacros reload` 即可运行。
文中用到的每个 API 都能在 [API 参考](../api/) 中查到，每篇讲解都附有指向
对应 API 页的链接。

| 示例 | 脚本类型 | 演示内容 |
| --- | --- | --- |
| [自动问候与关键词应答](./1.chat-automation) | 事件宏 | 在 `config.event.on` 中声明 `world:join` 与 `chat:receive`，按 `payload.type` 分发，读取 `ChatComponent` |
| [实时状态 HUD](./2.hud-overlay) | 服务 | `world` 生命周期的服务、带节流的 `tick` 处理、用稳定 id 调用 `hud.addText`、在 `dispose()` 中清理 |
| [按键切换助手](./3.keybinds) | 按键宏与服务 | 带 `default-key` 的 `config.keypress`、模块作用域中的切换状态、程序化 `input.registerKeybind`、`input.set` |
| [持久化伤害统计](./4.persistent-state) | 服务 | 统计 `player:damage`、用防抖定时器 `storage.put`、通过 `command.register` 注册自定义 `/stats` 命令 |

::tip
初次接触 NeoMacros？建议先阅读[第一个脚本](../guide/first-script)指南——
这些示例默认你已经知道 `config/neomacros/` 的位置以及 `/neomacros reload`
的作用。
::

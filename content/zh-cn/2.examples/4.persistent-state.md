---
title: "持久化伤害统计"
---

一个服务，统计你受到的伤害，把总计保存在 [storage](../api/modules/core/storage) 中
使其在重载与重启后仍然存在，并通过自定义的 `/stats` 客户端命令暴露出来。
它有意在一个小而实用的脚本里组合了三个子系统：事件、存储与命令。

## 它做什么

- 统计 [player:damage](../api/events/player/player-damage) 事件：总次数、
  累计伤害、最大单次伤害，以及"重击"次数（单次伤害 5 点及以上）。
- 每 30 秒把总计写入 `storage`（卸载时再写一次），而不是每次受伤都写。
- 注册一条 `/stats` 命令打印总计，并支持 `/stats reset`。

## 脚本

```text
config/neomacros/
└── macros/
    └── services/
        └── damage-tracker/
            ├── neomacro.yml
            └── index.js
```

`neomacro.yml`：

```yaml
name: damage-tracker
version: 1.0.0
author: you
description: Count damage taken, persist totals, expose /stats
permissions:
  - command
config:
  service:
    lifecycle: world
    autostart: true
```

`index.js`：

```js
// Counts damage taken, persists totals on a debounce, adds a /stats command.
const { command, chat, events, storage, thread } = neo;

const STORAGE_KEY = "stats";
const SAVE_INTERVAL_MS = 30000;
const HARD_HIT_THRESHOLD = 5;
const EMPTY_STATS = { hits: 0, total: 0, biggest: 0, hardHits: 0 };

let stats = loadStats();
let saveTimer = null;
let statsCommand = null;

export function startup() {
    events.on("player:damage", (event) => {
        stats.hits += 1;
        stats.total += event.amount;
        stats.hardHits += event.amount >= HARD_HIT_THRESHOLD ? 1 : 0;
        if (event.amount > stats.biggest) stats.biggest = event.amount;
        chat.actionbar(`Damage so far: ${stats.total.toFixed(1)}`);
    });

    saveTimer = thread.every(SAVE_INTERVAL_MS, persist);

    statsCommand = command.register({
        name: "stats",
        description: "Show or reset your persisted damage stats",
        args: {
            action: command.arg.word().optional(),
        },
        handler(ctx) {
            if (ctx.args.action === "reset") {
                stats = { ...EMPTY_STATS };
                persist();
                chat.log("Damage stats reset.");
                return;
            }
            for (const line of reportLines()) chat.log(line);
        },
    });

    for (const line of reportLines()) chat.log(line);
}

function loadStats() {
    const stored = storage.get(STORAGE_KEY);
    if (!stored || typeof stored !== "object") return { ...EMPTY_STATS };
    return {
        hits: numberOr(stored.hits),
        total: numberOr(stored.total),
        biggest: numberOr(stored.biggest),
        hardHits: numberOr(stored.hardHits),
    };
}

function numberOr(value) {
    return typeof value === "number" && Number.isFinite(value) ? value : 0;
}

function reportLines() {
    return [
        `Damage stats - hits: ${stats.hits}, total: ${stats.total.toFixed(1)}`,
        `Biggest hit: ${stats.biggest.toFixed(1)}, hard hits (>= ${HARD_HIT_THRESHOLD}): ${stats.hardHits}`,
        "Run /stats reset to start over.",
    ];
}

function persist() {
    storage.put(STORAGE_KEY, stats);
}

export function dispose() {
    persist();
    if (saveTimer) saveTimer.cancel();
    if (statsCommand) command.unregister(statsCommand);
}
```

## 工作原理

**事件。** [player:damage](../api/events/player/player-damage) 针对本地
玩家触发，携带 `amount`（损失的生命）与 `health`（受击后的生命值）。
处理器只修改模块作用域内的状态——开销极小，在战斗频率下也安全。衍生
分类（重击、最大单次）由同样的两个数字计算得出；这一步不碰磁盘。

**防抖。** 每次受伤都写盘是浪费；`thread.every` 每隔 30 秒真实时间调度
一次 `persist`，并返回定时器句柄。传给 [storage.put](../api/modules/core/storage) 的值
必须是可 JSON 序列化的纯数据——`stats` 是一个纯数字的扁平对象，符合要求。
每个脚本的存储彼此隔离、按源文件名键控，跨 `/neomacros reload` 与游戏
重启保留，且对其他脚本不可见。

**防御式读取。** 首次保存之前 `storage.get` 返回 `null`，因此
`loadStats` 回退为一个清零的新对象。`typeof`/`Number.isFinite` 检查意味着
存储损坏或被手工改坏时，脚本只会退回零值，而不会满屏 `NaN`。

**命令。** `command.register` 接收一个 spec：`name`、`description`、
可选的带类型参数槽 `args` 映射，以及接收解析上下文的 `handler`
（`ctx.args` 携带槽位值，`ctx.raw` 保留原始余串）。唯一的槽位 `action`
由 `command.arg.word().optional()` 构建——一个可省略的单词。处理器将它与
`"reset"` 比较；其余情况打印报告。

::warning
`command.register` 需要 `command` 权限，已在清单的 `permissions` 下声明。
在你用 `/neomacros trust damage-tracker` 授权一次之前，`/stats` 会失败。
::

**退出。** `dispose()` 立即持久化（快速重载也不会丢掉最后 30 秒）、取消
定时器使其无法再次触发，并按句柄注销命令。存储本身不会被删除——这正是
它的意义。

## 运行

1. 在 `.minecraft/config/neomacros/macros/services/` 下创建上述文件夹。
2. 执行 `/neomacros reload`，然后授权：
   `/neomacros trust damage-tracker`。
3. 进入世界——脚本会用当前总计问候你。挨几下发伤，然后执行 `/stats`。
   完全重启游戏后再执行 `/stats`：数字还在。
4. `/stats reset` 将一切清零（并持久化这次重置）。

::tip
如果命令根本没有出现，查看 `/neomacros errors`——未经授权的
`command.register` 会抛错，错误界面会显示脚本与行号。
::

## 尝试扩展

- 区分会话：再保留一个 `dispose()` *不*持久化的内存对象，报告里同时
  打印"本次会话"与"累计"两组数字。
- 同时统计治疗：订阅 [player:heal](../api/events/player/player-heal)
  （同样的 `amount` + `health` 结构），增加一个 `healed` 计数。
- `/stats export` 模式：用 `storage.get` 读回总计并用 `chat.say` 发出，
  方便粘贴到聊天里分享给队友。

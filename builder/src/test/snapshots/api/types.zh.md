# 类型定义

以下类型由引擎生成 guest 端真实 ES 类，可通过 `@neomacros/types` 导入并使用 `instanceof` 判断。

## StandaloneVec

数据

独立的自构造向量 cell（不属于任何门面）。

## Properties

| Property | Type | Description |
| --- | --- | --- |
| `x` | `number` | The X coordinate. (read-only) |
| `y` | `number` | The Y coordinate. (read-only) |
| `z` | `number` | The Z coordinate. (read-only) |
